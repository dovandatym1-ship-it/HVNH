## 🎯 Nội dung Trọng tâm Bài Tập Lớn (BTL)

1. **Giai đoạn Khởi tạo (Initiating)**:
   - Nghiên cứu khởi đầu, xác nhận giá trị (Business Need / Value), tính toán NPV / ROI / Payback Period.
   - Hiến chương dự án (Project Charter) với mục tiêu SMART.
   - Quản lý các bên liên quan (Stakeholder Register, Power/Interest Grid).
2. **Giai đoạn Lập kế hoạch (Planning)**:
   - Xây dựng Đường cơ sở đo lường hiệu suất (PMB - Performance Measurement Baseline).
   - Quản lý phạm vi (Scope Statement, WBS cấp độ 3-4, WBS Dictionary).
   - Quản lý tiến độ (Network Diagram, Ước tính 3 điểm PERT, Gantt Chart, Đường găng CPM).
   - Quản lý chi phí (Bottom-Up Estimation, Cost Baseline S-Curve, Contingency Reserve).
   - Quản lý nhân sự & rủi ro (RACI Matrix, Sổ đăng ký rủi ro, Kế hoạch ứng phó).
3. **Giai đoạn Thực hiện & Giám sát/Kiểm soát (Execution & M&C)**:
   - Quản lý thay đổi tích hợp (Change Request, CCB, Change Log).
   - Quản lý giá trị thu được (EVM: PV, AC, EV, CV, SV, CPI, SPI, EAC).
   - Báo cáo tình trạng hệ thống đèn giao thông (Traffic Light System), Issue Log.
4. **Giai đoạn Kết thúc (Closing)**:
   - Họp tổng kết Retrospective & Bài học kinh nghiệm (Lessons Learned).
   - Báo cáo đóng dự án (Final Project Closure Report), bàn giao và giải tán nhóm.
